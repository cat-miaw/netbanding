# Privacy Policy — NetBanding

NetBanding collects, stores, and shares **no personal data whatsoever**.

- No accounts, no ads, no analytics, no tracking, no crash SDK with user data.
- Package data is fetched from public ISP pages and stored only on the user's device (Room).
- The selected region preference is stored only on-device (DataStore).
- Tapping "open provider site" launches the browser; that site's own privacy policy applies there.
- Network access is used solely to download public price JSON from GitHub Pages.

Contact: via the app repository page.
